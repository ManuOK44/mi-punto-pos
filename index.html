Comisión por pago con tarjeta

Porcentaje que se suma al subtotal cuando el cliente elige tarjeta. Escribe la cantidad y presiona Guardar porcentaje. Usa 0 para no cobrar comisión.

Ejemplo: $100 + 3% = $103.00.

Impresión de tickets

Respaldo y datos

Exporta una copia antes de cambiar de teléfono, borrar Safari o reinstalar la app.

Instalación en iPhone: publica estos archivos en GitHub Pages, abre el enlace en Safari, toca Compartir y luego «Agregar a pantalla de inicio». Los datos se guardan en este dispositivo y en el almacenamiento de este sitio; no se sincronizan entre teléfonos. Los tickets no son facturas fiscales.
